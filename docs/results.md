## 3. Resultados

### 3.1 Qualidade do transcriptoma do intestino médio de *A. gemmatalis* (Fase 1)

#### 3.1.1 Completude do assembly (BUSCO)

A avaliação com BUSCO (insecta_odb10, n = 1.367) revelou alta completude do transcriptoma, com **94,2%** dos genes conservados de insetos representados (Tabela 1). A alta proporção de BUSCOs duplicados (52,6%) é esperada para assemblies de transcriptoma de novo gerados com Trinity, uma vez que múltiplas isoformas de um mesmo locus são representadas como transcritos independentes.

**Tabela 1.** Resultados da avaliação de completude do transcriptoma de *A. gemmatalis* (BUSCO v6.0.0, insecta_odb10).

| Categoria | n | % |
|-----------|---|---|
| Completos (C) | 1.288 | 94,2% |
| — Cópia única (S) | 569 | 41,6% |
| — Duplicados (D) | 719 | 52,6% |
| Fragmentados (F) | 23 | 1,7% |
| Ausentes (M) | 56 | 4,1% |
| **Total pesquisado** | **1.367** | — |
